# portfolio-resume

Интерактивное одностраничное портфолио разработчика, созданное на Vue 3, TypeScript и современном frontend-стеке.

Проект представляет собой персональное резюме в формате цифрового интерфейса с индустриальным стилем оформления, анимированными секциями, демонстрацией проектов, навыков и возможностью экспорта в PDF.

## Демонстрация проекта

После публикации проект будет доступен по ссылке:

🔗 **GitHub Pages:** `https://<username>.github.io/<repository>/`

## Технологический стек

* **Vue 3** — основной frontend-фреймворк
* **TypeScript** — статическая типизация
* **Vite** — сборщик и dev-сервер
* **Quasar Framework** — библиотека UI-компонентов
* **Tailwind CSS** — utility-first стилизация
* **GSAP** — анимации интерфейса
* **Puppeteer** — генерация PDF
* **Node.js** — вспомогательные серверные задачи

## Возможности

* Одностраничное адаптивное резюме
* Индустриальный / инженерный стиль интерфейса
* Анимации переходов и появления элементов
* Интерактивная секция проектов
* Визуализация навыков и опыта
* Экспорт портфолио в PDF
* Поддержка статического и серверного режима генерации PDF
* Настройка под статический деплой


## Работа с PDF

Проект поддерживает два режима работы с PDF.

### Статический режим

Используется заранее созданный PDF-файл, размещённый в директории публичных ресурсов.

Пример конфигурации:

```env
PDF_MODE=static
PDF_FILE=portfolio.pdf
```

В этом режиме файл напрямую скачивается из опубликованного приложения.

### Серверный режим

Используется Node.js сервер с Puppeteer для динамической генерации PDF.

Пример конфигурации:

```env
PDF_MODE=server
```

## Деплой

Проект подготовлен для статического размещения.

Перед публикацией необходимо:

1. Настроить корректный `base` путь в конфигурации Vite.
2. Проверить пути к статическим ресурсам.
3. Выполнить production-сборку:

```sh
npm run build
```

После этого содержимое директории `dist/` может быть размещено на:

* GitHub Pages
* любом другом статическом хостинге

